# 今日待办（TodayTodo）

> 把今天要做的事，一件一件变少。

## 宣传视频（30 秒）

https://github.com/peopleonethree/-Today-Work/raw/main/docs/promo-30s.mp4

## 它能做什么

- **说话就能记事**：按下说话，待办自动成条；念错的字，它记得住、还会替你改对
- **越用越懂你**：人名、地名、行话说错一次它就记住，下次自动纠正
- **做完就划掉**：待办、已办、笔记，一天的事清清楚楚
- **数据全在本机**：不联网也能用，隐私放心
