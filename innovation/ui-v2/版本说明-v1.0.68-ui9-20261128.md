## 本版变化（相对 v1.0.68-ui3）

### 1. 新功能：常用词档案库（`a9143fb`）

「常用人名」升级为个人常用词与语音识别纠错档案库，设计详见《常用词档案-设计说明.md》。

- **边界**：管「常用且易被语音识别错的词/短语/短句」（人名/时间/地点/人物/专业名词/行业术语等 7 类）；
  不改原生语音引擎本身（只在结果文本上纠错）、不做云端同步、单机上限 500 条。
- **数据**：localStorage 独立档案（`today-todo:v1:voiceArchive`），每条含正确写法、误识别列表（多个）、
  分类、使用场景、口音差异、备注、启用开关、命中次数/最近命中、来源（手动/导入/沉淀）；
  读取时夹回已知形状，坏数据丢弃不崩。
- **交互**：设置 → 「常用词档案（N）」→ 管理（检索/新建/编辑/停用/删除二次确认/批量粘贴导入/试跑/导出）；
  语音识别后发送前自动纠错（可关）→ 用户手改结果 → 弹「沉淀」卡片一键入库 → 下次识别优先按档案纠错。
- 旧「常用人名」（紫竹青禾、楚星云）经一次性迁移自动入档；试跑同时支持精确替换与拼音兜底
  （实测「楚星运 → 楚星云」「避设实物 → 毕设实物」命中正确）。

### 2. 下线旧导入功能（`009a735`）

QQ/微信好友导入、粘贴昵称等仅为摆设（无真实数据源），本版统一下线，`orig/` 冻结基线不动，
采用「构建期定点替换 + 运行期 DOM 清理补丁」：

| 移除项 | 手段 |
|---|---|
| 常用人名输入框、从文本导入、保存常用人名 | `patches/cleanup-legacy.js`（新增）删 DOM（保留同区块「联系人与通话」）；`build.mjs` 定点替换让识别纠错不再读 `prefs.voiceNames`、加载时清空遗留值 |
| 粘贴昵称 | `patches/paste-import.js` 整个删除、移出补丁链（`ddaa3a4`/`25aa87b`/`221df75` 随之失效） |
| 词库面板「批量导入人名」「导入通话记录」 | DOM 移除 + `message-workbench.js` 删除 importNames/importCalls/parseCalls/bindImport，目录不再读写 `imported`（存量导入记录失活） |
| 档案库「从常用人名导入」按钮与一次性迁移 | 从 `voice-archive.js` 删除（数据源已下线） |

不受影响：手动添加词条、管理联系人、同步到当前账号词库、查词、消息发送、待办/笔记语音输入、
词库人名词条的识别纠正（`restoreVoiceNames` 保留）。

### 3. 修复：档案库弹层小屏按钮不可达（`009a735` 内）

真机复现根因：早前的 kb-stable 键盘稳定层在键盘弹出时把弹层 `max-height` 钉死在「静止时高度」
（765px），超出被键盘压缩后的视口（533px），表单底部「取消/保存条目」和列表条目「删除」按钮
被顶出可视区。修法：kb-stable 增加 `data-kb-skip` 豁免约定，档案库弹层改用 flex 列布局 +
`dvh` 限高 + 表单/批量面板各自内滚、子面板展开时压缩列表高度。桌面端新增 6 项
「键盘压缩视口」可达性用例复现该条件；真机复验弹层高度 765→469，按钮正常可达、闭环成功。

### 4. 修复：键盘基准采样竞争（`d1a5374`，11-27）

快速「收起→再弹出」时，上一轮 `release()` 的 200ms 定时器落进下一轮弹出动画，
`captureRest()` 把「无键盘高度」记成动画中间值（869 → 802），下次锁定按矮高度锁、弹层上跳 67px。
现在 `captureRest()` 在原生内边距已离开基准时跳过采样；复测连开连关 3 轮锁定高度稳定 869px。

### 5. 打包通道与签名迁移（`40d86ab` 记录，11-27）

P2 打包通道打通（JDK + build-tools 装机包重签）；2026-11-27 起装机包统一用 `todaytodo.jks`
签名。旧钥匙 `dac1e506…` 签的 `v1.0.68` 原包无法覆盖安装（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`），
回退到旧签名必须 `pm uninstall`（清数据）或先用同钥匙重签——详见《测试报告.md》与脚本头部注释。

（`ddaa3a4` 粘贴昵称导入曾随 ui7 装机，后随第 2 项下线一并移除。）

   （当前写入链路已实测正常，与本版改动无关），请在档案库重新添加。
