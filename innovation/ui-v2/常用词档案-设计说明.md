# 常用词与语音纠错档案库 —— 设计说明

> 版本：v1（2026-11-28）
> 载体：`innovation/ui-v2`，新增补丁 `patches/voice-archive.js`，不改 `orig/`、不改 dex、不改 `index.html`。
> 前身：设置页「常用人名」单个 textarea（`prefs.voiceNames`，`normalizeVoiceNames` 只保留 2–4 汉字）。

## 一、功能边界

### 做（客户端可确定性验证的部分）

| 能力 | 实现位置 | 说明 |
|---|---|---|
| 词条持久化 | `localStorage` 键 `today-todo:v1:voiceArchive`（走 `AppStorage`） | 与 App 其余数据同命名空间、同一套容错封装；写失败不抛异常、不影响识别主流程 |
| 可检索 / 编辑 / 删除 | 档案库 `<dialog>` | 搜索覆盖正确写法、误识别、场景、备注四类字段 |
| 识别后自动纠错 | 拦截 `window.VoiceHost.result` + 发送前兜底 | 覆盖系统内嵌识别、网页版 `SpeechRecognition`、录音转写三条来路 |
| 纠正沉淀 | 发送时对比「本次交给 App 的文本」与「用户最终文本」 | 只在用户点发送/存入待办时提示，确认后才写档案 |
| 撤销 | review 态小条 | 误纠可一键回到原始识别结果，命中计数同步回滚 |

### 不做（明确写清，避免误期待）

1. **不改识别引擎本身**。系统的语音识别器（小米小爱 / Google 语音服务）不对外开放热词或语言模型接口，所以「优先参考档案」只能体现为**识别文本的确定性后处理**（精确替换 + 拼音同音/近音替换），不是给声学模型加偏置。完全不像的音（重口音、方言音变）仍需用户把「误识别结果」登记进档案。
2. **不联网、不上传**。档案只在本机；纠错在本地计算，不走大模型、不消耗额度。
3. **旧「常用人名」入口已下线**（2026-11-28 二期）：`#voice-names` 文本框、`从文本导入`、`保存常用人名`、`粘贴昵称` 均已移除（`patches/cleanup-legacy.js` + `build.mjs` 定点替换），识别纠错不再读 `prefs.voiceNames`，名字纠错只认档案库与词库人名词条。
4. **不做跨设备同步**。没有账号云端，换机需自己导出/粘贴。
5. **不做自动学习**。识别错了但用户没改，不猜；只有用户手动改过并点「记住」才沉淀。

## 二、数据结构

存储键：`today-todo:v1:voiceArchive`

```jsonc
{
  "v": 1,
  "settings": { "auto": true },   // 识别后自动纠错总开关
  "updatedAt": 1795800000000,
  "entries": [
    {
      "id": "va_m3k9x2ab",   // 稳定 id，编辑/删除/计数的锚点
      "kind": "person",      // person 人名 | place 地点 | time 时间·日程 | term 专业名词 | phrase 短语·句子 | other 其他
      "correct": "欧阳明宇",  // 正确写法，1–40 字，必填，同一 kind 下唯一
      "wrong": ["欧阳明雨", "欧阳明语"],  // 常见误识别，≤8 条、每条 1–40 字
      "scene": "开会通知",    // 使用场景，≤30 字
      "accent": "",          // 个人口音与普通话差异，≤60 字；非空即启用近音匹配（见下）
      "note": "",            // 备注，≤120 字
      "enabled": true,       // 单条停用，不影响其它条目
      "hits": 0,             // 使用频率：被纠错命中自动 +1
      "lastHitAt": 0,
      "source": "manual",    // manual 手填 | import 导入 | learn 纠正沉淀
      "createdAt": 1795800000000,
      "updatedAt": 1795800000000
    }
  ]
}
```

约束：条目 ≤ 500、单条 JSON ≤ 4 KB、整体 ≤ 512 KB；超限拒绝写入并提示，不清空既有数据。

## 三、纠错匹配规则（可解释、可测）

按顺序两遍，都只在实际命中时才改字：

1. **误识别精确替换**：把每条 `wrong` 按长度降序在文本里做字面替换 → `correct`。长度 ≥ 2 才参与（单字替换误伤太大）。
2. **拼音同音 / 近音替换**：用 `window.TodoNamePinyin`（pypinyin 派生，已随包分发）把 `correct` 转成无声调音节串，在识别文本的连续汉字上滑等长窗口：
   - 拼音串完全相同、且窗口文字 ≠ `correct` → 替换（中文识别错误的主流形态）；
   - 条目 `accent` 非空时，额外容忍常见口音混淆：`zh/z`、`ch/c`、`sh/s`、`n/l`、`f/h`、`r/l`、`ang/an`、`eng/en`、`ing/in`、`iang/ian`、`uang/uan`；
   - `correct` 长度 < 2 或 > 8 不参与拼音匹配；
   - 窗口文字若正好是**另一条档案的正确写法**，不替换（避免两条档案互相打架）；
   - 长条目优先，同位置只替换一次（占位不重叠）。

命中后：`hits+1`、`lastHitAt=now`，写盘做 400ms 去抖。

## 四、交互流程

### 1. 建档案

设置 → **常用词档案（N）** → 打开档案库：

- 顶部：搜索框、类型筛选、排序（频率 / 最近使用 / 新增）；
- 列表：每条显示正确写法 + 类型 + 命中次数 + 误识别预览，右侧 开关 / 编辑 / 删除（删除需点两次：先变「确认删除」，3 秒后复原）；
- 「新建一条」展开表单：正确写法（必填）、类型、常见误识别（一行一个）、使用场景、口音差异、备注；保存前校验长度、同类型重名合并 `wrong`；
- 底部：自动纠错开关、批量粘贴、导出文本、试跑一句。

「批量粘贴」接受两种行格式（行首序号 `1.` / `3、` 自动去掉）：

```
欧阳明宇 | 欧阳明雨、欧阳明语
毕设实物
```

「试跑一句」把输入的一句话过一遍纠错引擎，显示改前/改后与命中的条目，用于确认档案真的生效（不依赖麦克风，也能在真机上自证）。

### 2. 识别后纠错

```
说话 → VoiceHost.result → 档案纠错 → App 自己的 panelSpokenText（数字/时间）→ review 态文本
```

review 态在输入框上方出现一行小条：`已按档案纠正 2 处 · 撤销`。点「撤销」把这两处还原成原始识别结果，`hits` 同步回滚。

### 3. 纠正沉淀（越用越准的闭环）

用户在 review 里把 `张山` 改成 `张珊` 并点「发送给助手」/「存入待办」：

1. 用「公共前后缀裁剪」求差：`from=张山`、`to=张珊`；
2. 约束：两侧都非空、各 ≤ 12 字、至少一侧含汉字，否则不提示（补标点、大段重写都不学）；
3. 底部弹出：`记住这次纠正？张山 → 张珊` [记住] [忽略]，8 秒不点自动忽略；
4. 点「记住」：同 `correct` 条目存在则追加 `wrong`，否则新建条目（2–4 汉字猜 `person`，其余 `phrase`，`source=learn`）；
5. 下次同样的误识别在识别阶段就被自动改对。

## 五、验收标准

| # | 场景 | 期望 |
|---|---|---|
| A1 | 新建 3 条不同 `kind` 的档案，重开档案库 | 3 条都在；`localStorage` 里 `voiceArchive.entries` 长度为 3 |
| A2 | 搜索「开会」 | 只留下 `scene` 含「开会」的条目 |
| A3 | 删除一条 | 点一次变「确认删除」，再点消失；重开不复现 |
| A4 | 单条停用 | 该条不再参与纠错，`enabled=false` 落盘 |
| B1 | 档案 `毕设实物 / 误识别 避设实物`，试跑「明天带避设实物去实验室」 | 输出「明天带毕设实物去实验室」，提示命中 1 处 |
| B2 | 档案 `欧阳明宇`，输入「通知欧阳明雨开会」 | 输出「通知欧阳明宇开会」（拼音同音，无需登记误识别） |
| B3 | 档案 `毕设实物` 且带口音标记，输入「毕社实物」 | 拼音近音命中，输出「毕设实物」 |

| C1 | 真机：review 里手改一处后发送 | 出现「记住这次纠正」，点记住后档案新增，`wrong` 含改前文字 |

| D2 | 批量粘贴 `1. 欧阳明宇 \| 欧阳明雨` | 生成 1 条、`wrong` 1 条，行首序号不残留 |

## 六、已知限制

- 拼音表按单字取音，**多音字**取的是主读音，`长/重/行` 这类可能匹配不到；
- 每次纠错只处理「一条档案一次命中」，同一句里同一条目出现多次时按窗口逐个替换，`hits` 记 1 次（避免刷计数）；
- 沉淀只识别**单点替换**（前后缀裁剪后两侧都非空且 ≤12 字），整句重写、多处修改不学；
- `localStorage` 上限约 5 MB，档案与待办共用配额，写失败时只提示不清空。
