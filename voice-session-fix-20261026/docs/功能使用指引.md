## 常用的五条路线

1. **直接记一件事**：待办 → 输入内容 →（可选）时间、附件 → ＋。勾选后确认完成，它才进入已办。
2. **说完再决定去处**：麦克风 → 结束录音 → 检查文字 → ＋笔记 / ＋待办 / 发给助手。＋待办是填入输入框，还需点 ＋ 创建；导出是复制全文。
3. **把会议笔记变成行动**：笔记 → 记一条 → 输入或语音 → 提取待办 → 检查内容与时间、取消不需要的勾选 → 创建。后续修改笔记不会改变已创建任务。
4. **收好一页纸**：待办回形针 → 扫描 → 选彩色/灰度/黑白 → 提取文字 → 可复制 → 添加附件 → ＋ 创建任务。这是文档扫描，不是二维码导入。
5. **从旧笔记找答案**：笔记搜索关键词，或点「问」提问 → 看回答 → 点编号出处回到原笔记。问答需要模型；普通本地搜索和本地周统计可独立使用。

## 模型与数据范围怎么设置

用户菜单 → 设置 → 语音助手选在线大模型 → 添加模型 → 填兼容服务接口、模型名和密钥 → 探测并保存。可自动按任务挑选，或手动指定；模型对比在同一输入下比较多个模型。目录更新只修改可选模型名，有安装与回滚操作，不会安装、升级语音声学模型。本地规则无需模型服务；「本地大模型」需要可达的本机或局域网服务，并不表示手机已内置大模型。

经 `ConsentPolicy` 数据门禁的 AI 请求分三档：「允许联网」可发送内容到所配服务；「只在本机」禁止该路径发送正文，仍允许目录与探测请求；「关闭 AI」禁止该路径模型请求。发送前脱敏可以遮盖常见个人信息，不保证去除全部敏感信息。今日用量、每日上限和清空统计都是本机功能，token统计不等同服务商账单。这些设置不是设备断网开关：单独配置的音频转写、原生语音纠错和本地助手服务不能仅凭这三档推断完全不联网，使用前需分别检查。

本机账号可注册、登录、游客体验、切换、退出、改密与注销。找回密码依赖手机版系统设备验证。账号和业务内容均为本机存储，没有云端账号同步功能。安卓密钥使用原生安全存储；网页环境以设置中显示的存储状态为准。

## 语音数字与时间：核对后再创建

数字口述作用在笔记的离线转写结果，以及语音页「＋待办」转入的文字。两处共用分句规则：按标点分开数字句和普通句，只有符合规则的独立数字句转换，不能理解为全文任意数字改写。支持幺幺零→110、两千→2000、两百二十二→222、两万两千二百二十二→22222；洞幺两三四五六拐八勾→0123456789，保留前导零。例：「洞幺两三四五。明天下午三点开会。」→「012345。明天下午三点开会。」普通句子不改写；如「我有两三四五个朋友」「一百二十三元」「二零二六年十月」「一点二三四五」保持原样，两位短数字串也不套用逐位规则。

“动/沟/腰/有”等同音疑似错字只有满足候选条件才显示原文和数字候选，不会在任意句子里替换这些字。笔记中先结束录音、等待剩余转写，再核对并点「按数字采用」；采用后即时保存，可恢复识别原文。手工编辑后旧候选失效，保存失败会提示并保留重试机会。「＋笔记」直接存笔记与笔记编辑器的离线数字处理并非同一个入口，不承诺直接存入时自动套用数字规则。

待办时间提取：语音页点「＋待办」或直接手工输入后，输入框下方显示能解析的时间关键词和具体时间，支持如「明天下午三点」「半小时后」「下周三下午两点」。点选合适时间，再点加号添加；仅日期会给出9:00、14:00、20:00中尚未过去的建议，可改用「自选时间」或关闭建议。多个时间是供选择的备选，不会自动全部创建提醒；助手创建任务的额外提醒是另一路功能。选择前不会自动设置或覆盖提醒，过期候选无法采用。文字保持原句，不会把时间词自动删去。

待办数字核对：语音中既有数字串又有任务句子时，会按标点分别处理；清晰数字读法自动转换，疑似同音字显示原文与「按数字采用」候选，也可恢复。采用数字候选不会改变已选提醒时间；识别漏掉的数字仍需手工核对补充。编辑待办文字后旧候选失效。

## 保存、设备与识别边界

- 笔记停手后自动保存；离线转写每段提交后会尝试立即保存。停止录音后仍可能在转写，等待结束并核对保存状态。出现保存失败时保留当前页、重试或先复制正文；不要把文字已显示等同于已落盘。
- 语音页退出会保留未发送草稿；已转入待办、保存笔记或发给助手后会清除该语音草稿。待办仍需点 ＋ 创建。
- 当前 APK 的 `native-investigation/VoiceEngine.java` 显示 Sherpa ONNX Zipformer transducer、本地同音替换与标点处理，并尝试调用本机或局域网 `qwen3:8b` 服务纠错。代码中的 `whisper*` 桥接名和旧 SenseVoice/whisper 注释不能作为当前引擎型号依据。本地识别可独立出结果，但不能据此保证整个纠错链路绝不联网。
- 语音页录音转写优先本地；已配置音频识别服务时，在本地不可用或本会话本地处理挂起后可能使用网络转写。笔记离线转写依赖原生引擎；系统识别是否可用、是否联网由设备服务决定。
- 数字规则处理的是识别后文字，不能恢复音频识别漏掉的数字。用户已明确暂缓声学漏字处理；本轮不宣称数字识别准确率全过，不以自动化前端用例替代真机声学评测。
- 后台提醒依赖通知、精确闹钟、电池/自启动等系统设置，无法保证所有设备按时送达。扫描、设备验证、铃声等按容器能力和权限显示；录音附件上限60秒与语音转写的录音流程不同。
- AI 摘要、扩写、问答、周评及任务解析都可能出错，创建、替换或采纳前需核对。普通本地搜索、相关笔记、本地周统计不要求在线模型。
- 没有云同步、跨设备账号、协作分享、系统日历同步、周期重复任务和二维码/条码导入入口。删除操作不能视为可恢复回收站；已创建待办不会随来源笔记修改而同步。

## 当前指引接入约定

- `assets/js/guide-v2.js` 是无第三方依赖的普通脚本，需在 `app.js` 前加载；导出 `window.GuideV2.items` 与 `render(container,item,index)`。
- 当前宿主 `GUIDE_ITEMS` 已使用 `GuideV2.items`，`renderGuide` 已调用 `GuideV2.render(el.guidePager,item,guide.index)`；宿主处理点点、上一步、下一步、跳过、滑动、键盘和焦点。
- `assets/guide-v2.css` 在原样式后加载。给 `#guide-layer` 添加 `guide-layer--v2`，给 `#guide-pager` 保留原 ID；render 会添加 `guide-v2` class。渲染只替换容器内部，不操控外部弹层或全局导航。
- 主题通过已有 `html[data-theme="dark"]` 跟随。所有内容文字用 `textContent` 写入。无远程图片/字体依赖，无自动播放动画；尊重减少动态效果设置，summary 与按钮有可见焦点。
- 每页显示 `n / 10` 和 `aria-live` 页码；40张原生 details 卡片可键盘展开。移动端单列，较宽屏双列，单页独立滚动，不强迫用户逐张翻40页。
